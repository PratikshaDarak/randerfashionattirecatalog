# Neha Rander's Attire Catalog

A plain static HTML product catalog synced automatically with Google Drive (`https://drive.google.com/drive/folders/1SFQXzCrRSn4I2ZS-bECrAMjcIIYjAzx6`).

- Every subfolder in Google Drive becomes a catalog category using its exact folder name.
- Every photo added or removed in any subfolder updates the catalog automatically via [.github/workflows/sync-drive-catalog.yml](.github/workflows/sync-drive-catalog.yml).
- Host directly from the repository root on **GitHub Pages**, **Cloudflare Pages**, or **Netlify** with zero build steps.
